# 📱 Mobile Sales Dashboard – Power BI

## 📌 Project Overview

This project presents an interactive Mobile Sales Dashboard developed using Microsoft Power BI.

The dashboard provides insights into mobile sales performance across different brands, mobile models, cities, months, payment methods and days of the week.

## 🎯 Objectives

- Analyze overall mobile sales performance
- Compare sales across different brands and models
- Analyze monthly sales and quantity trends
- Understand customer payment preferences
- Analyze day-wise sales performance
- Identify geographical sales patterns
- Create an interactive business intelligence dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📊 Key KPIs

- Total Sales: 769M
- Total Quantity: 19K
- Total Transactions: 4K

## 🔍 Key Insights

1. Apple recorded the highest total sales among the brands shown, with approximately 161.62M.

2. Samsung followed Apple with approximately 160.04M in total sales.

3. July recorded the highest monthly quantity at approximately 1,700 units.

4. February recorded the lowest monthly quantity at approximately 1,451 units.

5. UPI was the most-used payment method, accounting for approximately 26.25% of transactions.

6. Saturday recorded the highest day-wise sales at approximately 115M.

7. iPhone SE generated approximately 60M in sales among the mobile models displayed.

## 📈 Dashboard Features

- KPI cards
- Interactive filters
- Monthly quantity trend
- Sales by city
- Customer rating analysis
- Payment method analysis
- Brand-wise performance
- Mobile model sales
- Day-wise sales analysis
